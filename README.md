# US Flight Delay Analysis — Excel Dashboard

Analysis of 9,999 US domestic flights from 2015 using Microsoft Excel.

## What's inside
- **Sheet1** — Raw dataset with 9,999 flight records (airline, origin, destination, delays, cancellations)
- **Sheet2** — Pivot tables: cancellation rate by airline & average air time per carrier
- **Final Dashboard** — Interactive summary dashboard

## Key findings explored
- Average departure delay by airline (AA had the highest at ~13.8 min)
- Cancellation rates: MQ had the highest (~30%), DL/B6/HA had 0%
- Delay causes: weather, air system, airline, late aircraft, security
- Departure hour patterns across the day

## Tools used
Microsoft Excel — Pivot Tables, Dashboard, Data Formatting
